## Policy

Documents are archived when they:
- Represent superseded or completed work
- Are temporary progress reports superseded by final summaries
- Contain one-time task records with no ongoing reference value

Archived documents should not be updated. If knowledge from an archived doc becomes relevant again, create a new document in the appropriate active directory.
